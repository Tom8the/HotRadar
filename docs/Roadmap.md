# HotRadar 开发路线

抖音「创作参考」切换为创作者中心全国创作热点榜，使用独立来源 `douyin-creator-hot`。旧同城创作热点已从来源管理移除，历史仍保留。抖音 App 原生无锡榜继续独立采集。

「来源管理」支持查看抖音精选内容最近采集状态、调整周期及启停自动采集。

「热点事件」支持按百度筛选，「趋势观察」提供百度来源的覆盖与曲线，「爆款内容」展示百度实时热搜选题线索及原始热搜指数。

工作台采集授权支持在弹窗中扫码、输入验证码及拖动滑块。登录完成后由服务器直接验证、采集并加密保存会话。部署见[采集授权与服务器迁移](Development.md#采集授权与服务器迁移)。

采集授权已接入工作台。抖音总榜提供匿名失败后的会话回退，抖音创作热点、微博无锡榜及两平台具体内容可逐项验证并启用。导入会话使用 Windows 和 Linux 通用的加密存储，兼容原 Windows 用户的 DPAPI。抖音原生无锡榜继续独立校验城市身份，并支持配置专用网络出口。操作见[采集授权与服务器迁移](Development.md#采集授权与服务器迁移)。

## 后续门槛

用户要求M4先使用现有真实历史，不等待满七天再开放功能。趋势页已展示实际采样、明确不足七天及覆盖缺口；24小时连续运行与七个自然日的连续覆盖验收仍未完成，不能以少量采样代替。内容池保留人工候选，微博热门与抖音精选正常会话自动采集均启用。

新平台仅在用户决定扩展后加入。AI摘要、潜力热点及具体内容增长需各自数据和质量验收；首期不制作或发布内容。

内容池展示具备完整来源字段的精选/热门候选，未定义爆款阈值。前一轮微博会话记录见SessionCollectionAcceptance.md。随后抖音SDK实测确认精选接口为POST /aweme/v2/web/module/feed/，使用本机会话可自动取得真实内容及互动，不需要签名回放或伪造。三批留存57条抖音观察，暂停/重新验证恢复及页面闭环通过，微博继续运行。两条原人工证据及此前自动观察保留。当前来源与限制见SDK验收（本地留档 `DouyinSdkAcceptance.md`）；30分钟调度启用，长期稳定性待观察。
