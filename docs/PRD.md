# HotRadar 首期产品需求

HotRadar 服务于 MCN 运营团队，让团队及时看到今天和最近七天的热点事件、爆火内容与趋势。范围覆盖多领域，AI 只是其中一类。名称统一为 HotRadar（热点雷达）。

## 首期范围

| 能力 | 展示要求 | 开发状态 |
|---|---|---|
| 今日热点 | 标题、平台、采样时间、原文、明确口径的源内指标 | M1/M2热榜及M3事件观察已实现 |
| 近七天趋势 | 真实采样时间序列、覆盖区间、数据缺口、源内变化 | M4已可用，历史不足七天明确标注；连续七日验收待积累 |
| 爆火内容 | 内容标题、作者、平台、发布时间、原始链接及实际可取的互动指标 | 微博热门及抖音精选正常会话自动采集已接入；保留人工样本；候选不等于确认爆款 |
| 事件聚合 | 将多个平台的同一事件线索关联，保留各自来源 | M3保守候选、人工合并/拆分/恢复已实现，自动关联待核对 |
| 热点摘要 | 基于来源解释可确认的标题与观测信息，支持原文追溯 | M3来源摘录与观测摘要已实现；正文新闻摘要及LLM仍待来源验证 |
| 增长信号 | 历史样本充分后展示增速及比较窗口 | 后续验证 |

首期不包含视频制作、写稿生产、自动发布、账号托管和达人管理。历史对话中的早晚报和自动发布方向已被后续大屏需求收窄。

## 数据与展示规则

1. 原始热榜排名、播放量与互动量分开保存。不同平台的指标不可直接相加。
2. 缺失播放量显示“来源未提供”，不填零；缺失历史采样不绘制完整曲线。
3. 时间在存储时记录时区，界面按 Asia/Shanghai 显示；今日使用本地日界，近七天默认包含今日。
4. 来源失败、数据陈旧、部分覆盖必须可见，单一来源异常不能伪装成正常全网状态。
5. 爆火内容必须链接到具体内容；事件热榜不能代替爆款视频池。
6. 增长比较须有至少两个可比时间点；“潜力热点”先作为观察信号，不承诺未来排名。

## 首轮来源验证

2026-10-29 用户确认增加百度：当前启用抖音话题热榜、微博热搜、百度实时热搜。百度为独立 `baidu-hot` 来源榜单，默认15分钟，支持来源管理、热榜筛选、事件关联与真实历史趋势。B站、知乎、RSS等继续暂缓。各来源长期稳定性仍需观察，百度历史从本次首次实际采集开始。

## 验收目标

- 选定来源的真实数据能够采集、入库、通过 API 读取并在页面展示，原文链接可打开。
- 事件和具体内容能区分；合并结果可追溯、可纠正。
- 七天窗口包含真实留存快照，采集不足七天时明确标注。
- 刷新失败和过期状态在页面可见，重启后历史记录保留。
- 演示数据必须明确标记，不能作为真实采集验收。

M1/M2/M3及M4趋势与大屏功能已实现；七天连续历史验收仍待后续。具体内容池保留两条人工核查样本，已接入微博热门与抖音精选全部分类正常会话采集。参见[路线](Roadmap.md)与抖音SDK验收（本地留档 `DouyinSdkAcceptance.md`）。

## 参考今日热榜的工作台要求

「创作参考」展示抖音创作者中心的全国创作热点榜，独立记录榜位、热度、采样时间及历史。原创作者中心无锡同城历史保留在其原有来源下。抖音 App 原生无锡榜仍通过「无锡榜」进入。

2026-10-19范围澄清：用户要求的抖音无锡榜是 App 搜索热榜中紧邻“抖音热榜”的原生城市榜，创作者中心同城榜与其不同。原数据改名为“无锡创作热点 · 创作者中心”并作为“创作参考”独立保留；原生无锡榜现以独立 `douyin-wuxi-app` 接入真实50条，见验收（本地留档 `DouyinAppWuxiAcceptance.md`）。不得用全国榜城市参数回显、创作热点或截图代替验收，也不能把旧来源历史移作新榜历史。

2026-10-15补充：微博卡片同样支持“🔥 总榜单”和“📍 无锡榜”，独立保留选择、采集状态、周期和历史。无锡榜使用微博移动端官方同城热搜及本机正常登录会话；每批校验官方城市名“无锡”与条目城市标识800863202，城市变化或登录失效不写入错误榜单。展示同城热度，不当作全国热搜指数或播放量。官方同城榜反映当地关注话题，可能包含外地事件，不能称为仅本地新闻。

2026-10-15新增：抖音卡片提供“🔥 总榜单”和“📍 无锡榜”两个切换标签，保留选择。总榜沿用现有数据；无锡榜使用抖音创作者中心实际同城筛选，独立采集、状态、周期和历史快照。列表序号遵循同城响应顺序，原始rank保留在详情及快照；不使用全国榜关键词过滤冒充同城榜。仍只有抖音与微博两个平台。

主导航采用热榜总览、热点事件、趋势观察、爆款内容、我的关注。热榜总览使用分类导航和多平台榜单卡片，每卡保留更新时间、排名、源内指标、更多、关注与局部刷新；提供平台/类别筛选、已采集内容搜索和卡片顺序恢复。

2026-10-29布局补充：选择全部平台时，1280px及以上的宽屏将抖音、微博、百度三张卡片并排展示在筛选栏下，避免百度被长榜单推至第二行。较窄桌面保持两列，移动端一列；单平台筛选和既有卡片排序不变。

工作台和大屏共用数据。大屏放大榜单与趋势，隐藏编辑入口，允许暂停轮播，来源过期与采集失败始终可见。普通工作台支持事件证据侧栏与人工纠正。

关注与分组先服务一个默认工作区，不在首期引入复杂账号同步、组织权限、通知机器人、商业套餐或内容生产。

## 首期来源与历史边界

M1最初接入抖音和微博。2026-10-29新增百度实时热搜。热点事件和趋势观察支持筛选百度，并保留真实来源证据、原始榜位和采样缺口。「爆款内容」页面复用选定日期的百度快照展示选题线索，具体视频和帖子的互动数据来自抖音和微博。百度热搜指数采用网页 `hotScore` 原值，榜单更新时间与采样时间分别保留，置顶条目无普通榜位。

历史从首次实际采集开始留存。七天验收需持续覆盖七个自然日；授权历史导入必须注明提供方与粒度。未在成功采集榜单中出现，不等于全平台热度为零。

## 验收分层

1. 来源验收：真实样本和字段映射、有效条目、异常状态、连续运行记录。
2. 系统验收：采集、持久化、API、页面闭环，重启恢复与重复任务幂等。
3. 业务验收：榜单/事件/具体内容可区分，趋势覆盖可解释，聚合错误可纠正。
4. 界面验收：真实数据下的筛选、刷新、详情、排序恢复与大屏浏览，不以静态页面或构建通过替代。

## M2已实现的工作台规则

分组/卡片顺序/平台关注/筛选/主题/自动读取偏好保存于当前浏览器，兼容M1关注与主题；不称为团队同步。筛选同时支持搜索、包含关键词（任一命中）、排除关键词（任一命中即排除）、隐藏来源广告和可比榜位上升。分类是本机关键词规则，不是AI事件判断。

来源启停与周期保存于数据库且留存前后配置。开放抖音、微博与百度，周期15/30/60分钟；暂停来源保留快照，可能完成在途请求。页面暂停自动读取与Worker采集独立，手动刷新仍可用。单卡刷新读选定日期已有快照，不请求上游平台。

## M3已实现的事件规则

事件观察池按选定北京时间日期的真实留存展示，跨平台优先、最近观测排序；“跨平台”按独立平台数计算，不按来源条目数计算。当前热榜数据只有话题，因此事件是关联观察对象，不能直接称为已核实新闻。自动关联标注待核对，数字不同、短关键词及较低相似度不自动合并；较宽相似线索仅供人工选择。

人工合并、拆分、恢复保存原因、版本、前后成员及关联依据；操作影响当前关系及历史视图，不覆盖原始快照。人工关系不接受自动追加，新别名可单独留存并人工处理。若涉及事件有后续修改，直接恢复被阻止，需根据当前来源手动修正。事件关注与标签保存于本地项目数据库的默认工作区，区别于浏览器中的平台关注。

来源摘要由本机确定性摘录生成，说明观测平台、话题、记录数并引用原始标题；保存输入证据ID、Provider、版本与签名，模型字段为null。重复/缓存采样计入留存记录数，但不当作独立传播次数。未读取报道正文，不补写事实背景、作者、互动指标或爆款预测。具体内容独立采集：微博热门和抖音精选返回候选与互动原值；增长比较与爆款判断仍待验收。

## 正常会话内容采集边界

微博热门推荐及详情、抖音正常页面SDK实际使用的精选全部分类POST接口验证通过后才启用独立内容任务，默认30分钟。每条保存真实链接、作者、带时区秒级发布时间、可用互动原值、采样时间与业务证据；抖音为点赞/评论/收藏/分享，微博为点赞/评论/转发。描述截断标注摘录，播放量未验证保持缺失。内容按采样日期读库，推荐可能个性化、包含旧内容，不代表全平台排行；原人工观察保留。

来源管理和爆款内容提供“采集授权”页面。用户在弹窗内的官方页面扫码，可点击页面中的按钮和验证方式，并可直接输入验证码或拖动滑块。微博热门内容与无锡同城共用一次登录。服务器验证并留存一批真实数据后启用对应来源，会话在采集服务器加密保存。原 Windows 安装继续兼容 DPAPI。Cookie 不进入 Git、业务 JSON、接口响应或日志。内容会话失效或上游拒绝时暂停内容采集，保留历史。页面暂停刷新只影响读取。

## M4真实趋势规则

用户明确要求先使用已采集历史。默认近七天包含顶部所选日期及前六日；当日、前一日和1至31日自定义窗口均按北京时间读取。每源显示有实际快照的日期数，不将其称为全天连续覆盖或百分比完整率；未留存日期明确标注，今日未结束单独标注。

榜位按来源自身排名展示，纵轴越靠上越靠前；抖音话题热度、微博热搜指数和百度热搜指数各自绘图，不合成总热度。一个事件有多个同平台成员时，各条话题保留独立序列。默认缩放至实际采样时段，并提供完整日期窗口，避免把少量当日点画成七天曲线。

每个状态点都引用实际快照或真实任务；没有按计划补造采样点。完整非广告榜单中未见成员记为“未在非广告采集榜单内”，部分解析未见记为未知，失败/未完成任务、缺失指标、暂停和断采分别保留。缺口及不可比点不连接曲线；缓存或部分解析的实际值可作空心点显示，不参与变化比较。

末两次变化需两条相邻、完整、未标缓存、解析版本相同且间隔不超过较小采样周期1.5倍的观测，并且没有穿过暂停或缺口；指标还需单位、提供方及定义一致。真实0保留，基期0不算百分比；下降仅称源内指标变化，不作传播或价格解释。首末观测跨度不是完整或连续在榜时长，曲线没有预测含义。

大屏显示覆盖不足、来源状态、曲线及轮播控制；轮播与自动读取分开暂停，退出大屏停止轮播。显式历史日期保持选择，“今日”在开启自动读取时随北京时间午夜更新。历史趋势使用当前事件成员关系，人工修正会影响视图，原始观测保留。
